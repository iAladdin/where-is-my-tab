Privacy Policy

Where Is My Tab · Effective August 1, 2026

Where Is My Tab is a local-first Chrome extension. It does not operate a backend, transmit browsing data to the developer, sell user data, or use advertising or analytics SDKs.

Information the extension handles

To provide tab search, organization, save-for-later, and trend features, the extension handles:

  • Open-tab titles, URLs, exact hostnames, and favicons.
  • Tab and window identifiers and state needed to switch, close, group, and move tabs.
  • Locally calculated activity signals, including last-switched time, active browsing duration, page-load counts, and audible playback transitions.
  • URLs and titles that the user explicitly saves to See it later.
  • Extension preferences such as the selected theme and card view.

The extension does not request Chrome identity access and does not collect the user's name, account email, passwords, authentication data, financial information, personal communications, precise location, form contents, or page contents.

How information is used

The information is used only to provide the extension's user-facing tab-management features:

  • Search and group existing tabs by title, URL, and exact hostname.
  • Switch to, close, save, and organize tabs across Chrome windows.
  • Display local browsing and playback trends by hostname.
  • Remember user-selected interface preferences.

Storage and retention

Extension data is stored only on the user's device in chrome.storage.local. Where Is My Tab has no developer-operated server and does not provide cloud synchronization. Stored data remains on the device until it is replaced by newer local data, pruned by the extension's retention rules, or removed when the user uninstalls the extension or clears its data.

Sharing and transfer

Where Is My Tab does not sell, rent, share, or transfer user data to the developer or any third party. It does not use user data for advertising, profiling, creditworthiness, lending, or purposes unrelated to tab management. No humans are given access to the user's locally stored extension data.

Remote code and external requests

All executable code is included in the extension package. The extension does not load remote scripts, remote modules, or WebAssembly, and it does not use dynamically evaluated code. Favicons are obtained through Chrome's built-in favicon API rather than a developer-operated service.

Chrome Web Store Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

If the extension's data practices change, this policy and the Chrome Web Store disclosures will be updated before the changed practices are introduced. The effective date above identifies the current version.

Contact

Questions or privacy requests can be submitted through the project's public issue tracker. Do not include private browsing data in a public issue.
