# Screenshot Shot List

Capture real screenshots from the running unpacked extension in Chrome. Do not use mockups for the store screenshots.

## Recommended Capture Setup

- Window width: `1440px` or wider
- Zoom: Chrome default `100%`
- Theme: capture at least the default `Aqua` theme
- Use realistic tab titles and URLs so search, grouping, and trends are easy to understand at a glance

## Required Screens

1. Hero + current tabs
   Show the refreshed header, centered search bar, domain cards, favicon slots, and compact icon actions.
2. Trends
   Show the main leaderboard, metric and time-window controls, and at least part of the weekly archive.
3. See it later
   Show grouped saved tabs with a mix of still-open and reopened items.

## Strong Optional Screens

1. Window actions
   Show a domain card with the `Merge to window` action and the profile-level `Gather solo tabs` action visible.
2. Theme variation
   Capture one alternate theme if you want to show personalization without changing the core workflow.

## Content Checklist

- The extension page is clearly replacing the Chrome new tab page.
- At least one multi-tab hostname group is visible.
- At least one subdomain is visible as a separate card.
- The search field looks active and central.
- Action icons are visible but not visually crowded.
- If you capture `Trends`, avoid using an empty state unless you are specifically showing the debug panel flow.
